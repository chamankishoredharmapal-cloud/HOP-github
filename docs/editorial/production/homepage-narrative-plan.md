# Narrative Plan: Homepage

- **Arc Type:** Journey Arc.
- **Tension Curve:** Arrival (Breath/Pause) → Exploration (Collections) → Grounding (Craft/Making) → Future (Heirlooms) → Mindset (Journal).

| Section | Element | Purpose | Tone Register |
