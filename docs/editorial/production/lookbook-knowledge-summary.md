## Lookbook Concept
**Theme:** "The Visual Silence"
**Concept:** A highly visual, low-text page that lets the craftsmanship speak for itself. It curates the best imagery across all collections (Kalyani brocades, Viara tissues, Megham pure zari) and frames them with brief, poetic captions.

## Deliverables Required
1. **Lookbook Page Content:** React page at `src/pages/Lookbook.tsx` focusing heavily on imagery, layout, and minimal text.
2. **Section Headlines:** Organizing the imagery by structural/emotional themes (e.g., The Warp, The Weft, The Drape).
3. **Image Captions:** Short, evocative descriptions of the textiles.

## Knowledge Gaps
- None. The page will rely on the existing image assets and UI components.

## Editorial Constraints
- **Primary Emotion:** Desire.
- **Secondary Emotion:** Wonder.
- **Arc:** Visual Journey.
- **No forbidden words:** Luxury, Premium, Exquisite, Perfect, Magic, Authentic.
- **Tone:** Let the visuals breathe. Copy should act only as a gentle guide.
