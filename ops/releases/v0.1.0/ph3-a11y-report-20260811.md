## Findings

### PH3-A11Y-001
- Bug ID: PH3-A11Y-001
- Severity: P2
- Location: src/pages/Checkout.tsx
- Description: Checkbox for "This is a gift" and "I acknowledge and accept the Return & Replacement Policy" do not have an explicit `id` mapping to the `<label>` `htmlFor`. While wrapping `<input>` inside `<label>` is technically accessible, Lighthouse and some older screen readers strongly prefer an explicit `id` mapping.
- Expected: Checkbox inputs should have an `id` that matches the `htmlFor` of their label.
- Actual: Missing `id` and `htmlFor`.
- Root cause: Attributes missing during development.
- Suggested fix: Add `id="isGift"` and `id="returnPolicyAccepted"` to the inputs and matching `htmlFor` to labels. (Fixed)

### PH3-A11Y-002
- Bug ID: PH3-A11Y-002
- Severity: P3
- Location: src/components/hop/HopFooter.tsx
- Description: The email newsletter subscription form is missing an explicit label for the email input field. It relies solely on `aria-label`.
- Expected: Form inputs should have a visually hidden `<label>` for best compatibility.
- Actual: Missing `<label>`.
- Root cause: Missing label element in footer form.
- Suggested fix: Add a visually hidden `<label htmlFor="footer-email">` and an `id="footer-email"` to the input. (Fixed)

### PH3-A11Y-003
- Bug ID: PH3-A11Y-003
- Severity: P2
- Location: src/pages/Checkout.tsx
- Description: Secondary text colors using `text-ink-soft/50` have poor color contrast against the light background.
- Expected: Text must meet minimum color contrast ratio of 4.5:1.
- Actual: Contrast ratio is too low for `text-ink-soft/50`.
- Root cause: Too low opacity in Tailwind class.
- Suggested fix: Change `text-ink-soft/50` to `text-ink-soft/70`. (Fixed)

### PH3-A11Y-004
- Bug ID: PH3-A11Y-004
- Severity: P2
- Location: src/pages/Cart.tsx & src/components/search/SearchModal.tsx
- Description: Multiple helper texts and icons use `text-ink-soft/50` which fails color contrast guidelines.
- Expected: Helper text and active icons should pass color contrast requirements.
- Actual: Opacity is too low.
- Root cause: Same as PH3-A11Y-003.
- Suggested fix: Change to `text-ink-soft/70`. (Fixed)
